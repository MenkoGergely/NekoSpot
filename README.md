# NekoSpot

A cross-platform mobile application built with **.NET MAUI** and **C#** for logging and tracking cat sightings, complete with local SQLite persistence, camera integration, and interactive map views.

## Features

- **Full CRUD Functionality:** Create, view, edit, and delete cat entries (name, coat color, date seen, description, and photo).
- **Local Database Storage:** Offline-first data persistence using **SQLite**.
- **Camera & Media Integration:** Capture new photos directly with the device camera or attach existing images to entries.
- **Map Integration:** Pin and view sighting locations on an interactive map.
- **MVVM Architecture:** Clean separation between UI views, business logic (`ViewModels`), and data models (`Models`).

## Tech Stack

- **Framework:** .NET MAUI
- **Language:** C#
- **Architecture:** MVVM (Model-View-ViewModel)
- **Database:** SQLite
- **Device Features:** Camera / MediaPicker & Maps integration
